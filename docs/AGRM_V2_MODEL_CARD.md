# AGRM v2 model card

## Identity and purpose

This is an optional research model for nine-class relations between two nodes
in an explicitly supplied spatial constraint graph. It is not a language model,
robot controller, general theorem prover, or general intelligence system.
The purpose is to measure whether auxiliary Gram-geometry supervision helps
when the graph integrator is learned rather than analytically supplied.

All 60 trained checkpoints are retained under
`reports/geometric_v2/experiment/checkpoints/`. Every JSON file records its
architecture, dimensions, recurrence count, weights, model digest, protocol and
source hashes, training data digest, seed, sampling digest, cost, and learning
history. The displayed inference example uses seed 103 at 512 tasks and
lambda=0.2 by a simple declared convention, not final-score selection.

## Architecture

| Item | Fixed architecture | Learned architecture |
|---|---|---|
| Learned parameters | 180 | 4,228 |
| Relation embedding | Nine vectors in R^16 | Nine vectors in R^16 |
| Integration | Exact least-squares graph solve | 16 shared local message/GRU rounds |
| Latent coordinate map | Integrated embeddings | Learned linear map from hidden states |
| Query gauge | Queried reference node at zero | Queried reference node at zero |
| Output | Common two-axis sign-factorized nine-class head | Same head |
| Oracle at inference | None | None |

The learned architecture retains graph locality, signed edge presentation,
query anchoring, and the sign-factorized output head as priors. Removing the
solver does not remove every engineered prior. A 16-round network also has a
finite message horizon and is not guaranteed to extrapolate to arbitrary graph
diameters. It receives no text or node-name semantics.

## Data and supervision

Synthetic, consistent exact unit-grid constraints are generated by the frozen
v1 code. Training depths are 1-4, with distractors. Three nested subsets provide
32, 128, or 512 tasks. Both objectives receive categorical answers. The
lambda=0.2 objective additionally receives exact node-coordinate Gram targets.
No training corpus of natural language, human behavior, or real-world spatial
measurements is used.

Evaluation covers 256 examples in each of five families, with one shared final
seed. Tree shape, chain depth, and cyclic topology change, but the underlying
relation algebra does not. Repeated semantic templates can occur. Development
and final tasks have different generator seeds; they are not a proof of
semantic independence. The final cases are distributed for verification and
must not be treated as an untouched test in future model development.

## Outputs and authority

Inference returns the inherited typed `Advice` contract. It binds the exact
task and model digests, a relation or abstention, integer confidence, and an
integer latent residual diagnostic. Confidence is an uncalibrated model
probability. The default threshold is 0.6; disconnected queries always abstain.
No inconsistency detector is claimed for v2, and the residual is not used as
a satisfiability test. Consistent graphs are the evaluated domain.

The model can supply content to the existing `propose_advice` adapter, which
registers a proposal to the sandbox's message field. The model's confidence,
JSON checkpoint, digest, and prediction are never a warrant or capability.
The existing kernel still owns every later authority transition. It remains
a trusted-process prototype: this experiment does not add hostile-process
isolation, independent assessors, evidence resolution, or an external adapter.

## Validation and limits

Read `AGRM_V2_RESULTS.md` for all results, including the frozen
decision rule (locally frozen, not externally registered), observed failures,
costs, and confidence coverage. Structural tests verify absence of a graph
solve in the learned path, nonzero and numerically checked geometric gradients,
permutation/padding behavior, bounded JSON loading, and the proposal boundary.

Successful benchmark performance does not establish general spatial reasoning,
truthfulness, alignment, operational safety, or fidelity to a proprietary
researcher's undisclosed mechanism. Improvement from geometry supervision may
be due to extra coordinate labels. The fixed and learned models differ in
capacity and computation. All five initialization seeds share the same data
pool and test seed. Independent replication remains necessary.

## Distribution and governance

The checkpoint format is JSON; it does not unpickle executable objects. The
loader caps input size at 2 MB, rejects duplicate keys and nonfinite weights,
checks tensor names/shapes, and verifies the model digest. This is an integrity
check, not proof of publisher identity. The owner has not selected a
distribution license. Local implementation and validation do not satisfy the
repository's independent governance review or production gate.
