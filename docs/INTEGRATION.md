# Integration contracts: planned, not connected

Adiona is a new seed repository. No imports, live calls, subtree copies or writes
to Fidelis, ERBA or Metanoia occur in its code or demo.

## Fidelis boundary

Keep the orchestrator thin. An adapter should translate each authority's output
into a neutral, typed envelope without rewriting an advisory claim as an ALLOW.
EthicsCouncil or a successor supplies substantive duties/rights assessments;
meaning-assay supplies qualified warrant. The executor consumes neither free-form
model prose nor an unqualified consensus.

A future contract must include exact action digest, evidence object references,
qualification envelope, assessment method/version, uncertainty, issuer identity,
policy/jurisdiction, freshness, dissent and an explicit admissible use. Reject
missing information; do not fill it with a passing default. Contract tests must
mutate every binding field and show that the downstream gate rejects substitution.

## Metanoia boundary

Map verified external principals and grant ancestry to Adiona's authority
contracts. Do not import self-asserted role strings. A retry or a producer name is
not a new warrant. New evidence or review must initiate a full evaluation against
current policy and state.

The source verifier and source policy must themselves be pinned, independently
reviewed and externally protected. The proposed verifier must not approve its own
installation. No root token or configuration change is inferred from a model's
request to improve the system.

## ERBA boundary

Keep ERBA-0 and the frozen ERBA-1 design unchanged. E1-E6/M1-M2 motivated new
Adiona regressions; they do not retroactively alter the instrument's claims or
scores. Do not insert Adiona as an undisclosed change in a frozen experiment.

A proposed ERBA-D extension would add exact-action binding, malformed evidence,
revocation, replay, concurrency, semantic duty violations, recovery adequacy and
harmful inaction. It requires a separate immutable registration before model
exposure for a preregistered claim. Mark exploratory development honestly.

## Real actuator boundary

The first domain should be narrow and low-impact. Prefer an adapter with reliable
state inspection and idempotency support. Every sensitive read, outgoing message,
model-provider request, write and delegated call must be accounted for. Do not
leave an alternate credential in worker memory.

Atomically prepare and reserve the local execution record before dispatch. An
external timeout is UNKNOWN_EXTERNAL_STATE until reconciled. A reconciliation
observation needs authenticated origin, action correlation and evidence of the
actual outcome. A failed or unknown dispatch cannot free a possibly spent token.
This seed models the states only; it does not implement this adapter.

## Approval to integrate is not approval to deploy

Require matched negative controls, independent contract review, adapter-specific
fault injection, outcome verification and a recorded authorization scope. The
original repositories' green tests, Adiona's green tests, or the manuscript's
framework alone cannot confer deployment clearance.
